EXPERIMENT 11 - WEB-BASED RESUME

Files:
- index.html: Resume structure and content
- style.css: Responsive design and print styles
- script.js: Dark mode, mobile navigation, print/download button and current year
- bookora.apk: Android APK download for the Bookora project

Project links:
- StudySync live website: https://studysync-khushi.netlify.app/
- Bookora: use the Download Android APK link in the Projects section.

Run locally:
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser (or use Live Server).

Before publishing:
- Replace your.email@example.com with your actual email address.
- Add or update certification details if you have certifications.
- Review all resume details for accuracy.

GitHub Pages deployment:
1. Sign in to GitHub and create a new public repository named khushi-sanghvi-resume.
2. Upload index.html, style.css, script.js and bookora.apk to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the deployment to finish. Your site URL will be shown in Settings > Pages.

Note: The APK is approximately 37 MB. If GitHub rejects the file or the repository size becomes inconvenient, upload it as a GitHub Release asset and change the Bookora download link to that release asset URL.
